# Mi Camino en Ciencias de la Computación (OSSU)

Este repositorio está destinado a documentar y almacenar mi progreso, apuntes, ejercicios y proyectos desarrollados a lo largo del plan de estudios de la **[Open Source Society University (OSSU) - Computer Science](https://github.com/ossu/computer-science)**.

El repositorio original contiene el plan de estudios completo, explicaciones detalladas, enlaces de registro a los cursos oficiales, duraciones y comunidad.

## 📂 Estructura del Repositorio

Todo el contenido práctico, notas y avance específico de cada curso se encuentra estructurado en la carpeta **[`Camino`](./Camino)**:

- **[`Camino/01-Intro-CS`](./Camino/01-Intro-CS)**: Introducción al pensamiento computacional y programación básica.
- **[`Camino/02-Core-CS`](./Camino/02-Core-CS)**: Fundamentos requeridos (programación funcional/orientada a objetos, matemáticas discretas, sistemas operativos, redes, algoritmos, bases de datos y seguridad).
- **[`Camino/03-Advanced-CS`](./Camino/03-Advanced-CS)**: Cursos avanzados y electivas de especialización (compiladores, sistemas distribuidos, criptografía avanzada, etc.).
- **[`Camino/04-Final-project`](./Camino/04-Final-project)**: Proyecto final de integración de conocimientos.

Cada subcarpeta de curso cuenta con su propio archivo `README.md` listo para rellenar con notas de estudio, ejercicios resueltos y el estado de avance individual.
